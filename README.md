# Certificados · Pós-graduação — Download

Instaladores do programa que gera os certificados (declarações de aula) dos docentes da pós-graduação.
Nenhum deles pede senha de administrador.

## Baixar

| | Arquivo | Para quê |
|---|---|---|
| **1** | [**Instalar-Certificados-0.6.2.exe**](https://github.com/diogodimase-ctrl/Certificados-Download/releases/latest/download/Instalar-Certificados-0.6.2.exe) | **Programa principal.** É este que se usa no dia a dia. |
| 2 | [Instalar-Certificados-AHK-v27.exe](https://github.com/diogodimase-ctrl/Certificados-Download/releases/latest/download/Instalar-Certificados-AHK-v27.exe) | Plano B: versão antiga em AutoHotkey. Só se o programa principal não funcionar. Instala o AutoHotkey sozinho se faltar. |
| 3 | [AutoHotkey_2.0.31_setup.exe](https://github.com/diogodimase-ctrl/Certificados-Download/releases/latest/download/AutoHotkey_2.0.31_setup.exe) | O AutoHotkey avulso (o instalador do plano B já usa este). |

Clique no nome do arquivo e o download começa. Também dá para ver todos na página
[Releases](https://github.com/diogodimase-ctrl/Certificados-Download/releases/latest).

## Instalar

1. Abra o arquivo baixado.
2. Se aparecer a tela azul **"O Windows protegeu o computador"**, clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Clique em **Avançar** até o fim. O atalho **Certificados** aparece na Área de Trabalho.

O passo a passo completo está nos manuais, na pasta **Declarações\_Programa Certificados** do SharePoint
(Manual 1: instalação e uso · Manual 2: fluxo do Power Automate · Manual 3: processo de geração em detalhe).
